# Valencia Info Bot

Бот, который отвечает на вопросы о жизни в Валенсии, опираясь на реальный опыт из чатов местных экспатов — и сверяет факты с официальными источниками.

Спросил «как записать ребёнка в школу» — получил живой ответ с цитатами тех, кто это уже прошёл, плюс актуальные требования, адреса и часы работы с официальных сайтов.

## Зачем это

База знаний — ~40 000 обсуждений из русско- и украиноязычных групп Валенсии. Это не документация, а разговоры живых людей, и отсюда три инженерные проблемы, вокруг которых построена вся система:

- **Информация устаревает.** «Запись в консульство за неделю» (2024) и «теперь ждать месяц» (2026) — оба утверждения есть в базе, отвечать надо вторым.
- **Сказано один раз, дальше — отсылки.** Подробная инструкция написана в январе, а потом полгода «смотри выше».
- **Похожее ≠ релевантное.** Векторный поиск охотно тащит «что-то на ту же тему» вместо ответа на вопрос.

Как это решается — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Как устроено

**Хранение — три слоя:** неприкосновенный архив сообщений → треды (единица поиска, свежесть считается по последнему ответу) → извлечённые факты с двумя осями времени (когда факт верен в мире и когда мы о нём узнали). Новый факт гасит устаревший, ничего не удаляя.

**Поиск — три ступени:** гибридный поиск (векторы + полнотекстовый, слияние RRF) → реранкер → взвешивание свежести. Свежесть — множитель со «полом», а не сортировка: свежее побеждает при равной релевантности, но уникальный старый ответ не теряется.

**Наполнение — раз в сутки:** ночной прогон докачивает сообщения, пересобирает затронутые треды, считает эмбеддинги только для изменившегося, извлекает факты и гасит противоречащие.

**Ответы — сервис с HTTP API.** Telegram-бот и мобильное приложение — просто клиенты одного эндпоинта.

## Запуск

Нужен Docker и Python 3.11+.

```bash
cp .env.example .env    # заполнить POSTGRES_PASSWORD и OPENAI_API_KEY
```

Поднять базу — схема и функции поиска применятся автоматически:

```bash
docker compose up -d db
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Загрузить треды и посчитать эмбеддинги:

```bash
python scripts/load_threads.py data/<группа>/threads.json <группа>
```

Проверить поиск:

```bash
docker compose exec db psql -U valencia -d valencia -c "SELECT id, left(content,80), round(score::numeric,4) FROM hybrid_search('запись в школу документы', NULL, 5);"
```

Загрузка идемпотентна: повторный запуск обновит изменившиеся треды и пересчитает векторы только для них.
