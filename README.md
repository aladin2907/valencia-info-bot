# Valencia Info Bot

Бот, который отвечает на вопросы о жизни в Валенсии, опираясь на реальный опыт из чатов местных экспатов.

Спросил «как работает купон на школьные учебники» — получил живой ответ с суммами, ссылками и цитатами тех, кто это уже прошёл.

## Зачем это

База знаний — обсуждения из русско- и украиноязычных групп Валенсии. Это не документация, а разговоры живых людей, и отсюда три инженерные проблемы, вокруг которых построена вся система:

- **Информация устаревает.** «Запись в консульство за неделю» (2024) и «теперь ждать месяц» (2026) — оба утверждения есть в базе, отвечать надо вторым.
- **Сказано один раз, дальше — отсылки.** Подробная инструкция написана в январе, а потом полгода «смотри выше».
- **Похожее ≠ релевантное.** Векторный поиск охотно тащит «что-то на ту же тему» вместо ответа на вопрос.

Как это решается — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Как устроено

**Хранение — три слоя:** неприкосновенный архив сообщений → треды (единица поиска, свежесть считается по последнему ответу) → извлечённые факты с двумя осями времени (когда факт верен в мире и когда мы о нём узнали).

**Поиск — измеренная связка:** свой bge-m3 ищет по смыслу → пул 50 кандидатов → свой реранкер bge-reranker-v2-m3 → топ-8 тредов в ответ. Обе модели работают на своём железе, платные API для поиска не нужны. Что и почему было отвергнуто — [docs/QUALITY.md](docs/QUALITY.md).

**Наполнение — раз в сутки:** ночной прогон докачивает сообщения, пересобирает затронутые треды (окно 14 дней — на старый вопрос отвечают и через неделю) и считает векторы только для изменившегося.

**Ответы — сервис с HTTP API.** Telegram-бот и будущее мобильное приложение — просто клиенты одного эндпоинта `POST /ask`.

## Качество

Замерено на 50 реальных вопросах (25 про школы, 25 про документы; русский и украинский), пять раундов улучшений — [docs/QUALITY.md](docs/QUALITY.md).

| Метрика | Значение |
|---|---|
| Нужный тред в топ-5 | 72% |
| Нужный тред в топ-15 | 84% |
| Оценка ответа (0–5) | 3.8 |
| Покрытие эталонных фактов | ~73% |
| Галлюцинации | 1–3 из 50 |

## Быстрый старт

Нужен Docker. Модели скачаются сами при первом запуске (~2.5 ГБ), GPU не нужен.

```bash
cp .env.example .env    # заполнить OPENROUTER_API_KEY
docker compose --profile local up -d
```

Проверить, что всё живо:

```bash
curl -s localhost:8080/health
```

Загрузить свои треды и посчитать векторы:

```bash
docker compose run --rm ingest python scripts/load_threads.py data/<группа>/threads.json <группа>
```

Спросить:

```bash
curl -s -X POST localhost:8080/ask -H 'Content-Type: application/json' -d '{"question":"как записать ребёнка в школу"}'
```

Развёртывание на AWS с Supabase — [docs/DEPLOY.md](docs/DEPLOY.md).

## Данные

Выгрузки чатов в репозиторий не попадают — это приватная переписка реальных людей. Каталог `data/` в `.gitignore`, свежий клон приезжает с пустой базой. Для запуска нужны собственные выгрузки Telegram в формате `threads.json` (`thread_id`, `thread_date`, `text`) либо доступ к группам через `ingest` (нужен обычный аккаунт: боты не читают историю групп).
